# Verilog RTL Design & Verification

This repository contains my hands-on **Verilog RTL design and verification projects** as an undergraduate VLSI student.

I am using this repository to document my learning journey through practical RTL implementations, testbench development, simulation, and debugging.

## 📚 Current Projects

### 1. FIFO — First In, First Out

A FIFO is a memory structure where the **first data written is the first data read**.

The project covers:

* FIFO RTL design
* Read and write operations
* Full and empty conditions
* Verilog testbench
* Simulation and waveform analysis

### 2. FILO — First In, Last Out

A FILO structure follows the principle that the **first data written is the last data to be read**.

The project covers:

* FILO RTL design
* Data storage and retrieval
* Push and pop operations
* Verilog testbench
* Simulation and debugging
